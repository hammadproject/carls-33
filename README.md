Project

This is a Webflow-exported static website containing the HTML, CSS, JavaScript, images, fonts, and other assets required to run the site.

Run Locally

Extract the ZIP file.

Open the project folder in VS Code.

Open index.html with Live Server, or open it directly in a browser.

Deployment

Upload the complete project while keeping the existing folder structure unchanged. Do not upload only the HTML file because the CSS, JavaScript, images, and fonts are required.
